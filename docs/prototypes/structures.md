# Candidate structures — desktop Helper slot editor

All inherit Helper's existing Material controls, system text, tonal surfaces,
sidebar and top/bottom chrome. Content is an illustrative studio patch.

1. Socket list with a persistent inspector: fast capture; select a physical
   socket, edit destination and cable metadata while neighboring records remain
   visible. Primary action sends one connection, with an optional next-socket step.
2. Destination-grouped directory: recall from the gear end; group by the explicit
   Group field, then list complete destinations and their NT sockets. Socket-view
   toggle retains access to unused ports and the canonical physical inventory.
3. Guided recall worksheet: compare one recorded cable at a time, local progress
   checkboxes and next/previous controls. "Checked" is a user's session-only mark,
   never automatic cable detection or an NT preset property.
4. Native-socket matrix: all 20 identities arranged as inputs and outputs with
   compact destination labels, opening a stable detail panel. Explicitly a logical
   inventory, not an anatomically accurate module faceplate.
5. Editable patch ledger: dense rows with socket, destination, colour, tag, and
   group columns. Inline editing serves keyboard capture; narrow layouts must
   retain fields without horizontal scrolling or hidden validation errors.
6. Paired input/output lanes: two vertical lists share one editor underneath.
   Clearly independent ports, with no invented signal-routing lines or stereo
   pairing. Easy physical scanning but less comfortable for long destinations.
